mend applies AI-generated code edits in every common format — unified diffs, SEARCH/REPLACE blocks, V4A and JSON edits — locating each edit at the first of three matching tiers and writing every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```

Run it with the working directory as the root of a tree of text files (Node 22, standard library only). It prints what it changed, or why it failed.
